# 🎬 RealCinema – Movie Booking & Streaming Platform

A full-stack **Movie Booking & Streaming Web Application** built using **Node.js, Express, MongoDB, and EJS**.  
RealCinema allows users to explore movies, book tickets, and enjoy a modern cinema-style UI.

---

## 🚀 Features

- 🎥 Browse latest movies
- 🎟️ Book movie tickets
- 👤 User authentication (Login / Register)
- 🔐 Password reset functionality
- 🛠️ Admin movie management
- 📱 Fully responsive design
- ❤️ Clean red-themed cinema UI

---

## 🛠 Tech Stack

**Frontend**
- EJS
- HTML5
- CSS3
- Bootstrap 5

**Backend**
- Node.js
- Express.js

**Database**
- MongoDB
- Mongoose
